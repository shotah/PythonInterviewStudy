# Developer Cheat Sheet Collection

This document provides a curated list of cheat sheets for developers, categorized for easy reference during interview preparation and general development work.

## I. Core Programming Fundamentals & Algorithms

- **Big O Notation Cheat Sheet:** Crucial for algorithm analysis in interviews.
  - [Big O Cheat Sheet Examples](https://www.bigocheatsheet.com/)
- **Data Structures Cheat Sheet:** Quick reminders of common data structures (Arrays, Linked Lists, Stacks, Queues, Trees, Graphs, Hash Tables, Heaps). Focus on properties, time complexities, and use cases.
  - [Data Structures Cheat Sheet Example](https://www.interviewcake.com/data-structures-cheat-sheet)
- **Algorithms Cheat Sheet:** Summaries of key algorithms (Sorting, Searching, Graph algorithms, Dynamic Programming approaches). Focus on concepts and application.
  - [Algorithms Cheat Sheet Example](https://www.geeksforgeeks.org/must-have-algorithms-for-competitive-programming/)

## II. Programming Language Specific Cheat Sheets (Focus on your primary languages)

- **Ruby on Rails Cheat Sheet:** Key syntax, Rails conventions, routing, ActiveRecord, helpers, debugging.
  - [Rails Cheat Sheet Example](https://www.shortcutfoo.com/cheat-sheets/ruby-on-rails-4-api-cheat-sheet)
- **Node.js Cheat Sheet:** Core Node.js APIs, npm commands, async patterns, common modules.
  - [Node.js Cheat Sheet Example](https://overapi.com/nodejs)
- **React Cheat Sheet:** JSX, component lifecycle, hooks, props, state, React patterns, Redux/Context basics.
  - [React Cheat Sheet Example](https://devhints.io/react)
- **JavaScript Cheat Sheet (General):** Core JavaScript syntax, DOM, ES6+, built-in methods, browser APIs.
  - [JavaScript Cheat Sheet Example](https://devhints.io/js)

## III. Cloud & DevOps Cheat Sheets

- **AWS Services Cheat Sheet:** Overview of key AWS services by function (Compute, Storage, Networking, etc.).
  - [AWS Cheat Sheet Example](https://tutorialsdojo.com/aws-cheat-sheets/)
- **Kubernetes Cheat Sheet (kubectl):** Common `kubectl` commands for management and debugging.
  - [Kubernetes Cheat Sheet Example](https://kubernetes.io/docs/reference/kubectl/cheatsheet/)
- **Docker Cheat Sheet:** Docker commands for images, containers, volumes, networking, Docker Compose.
  - [Docker Cheat Sheet Example](https://www.docker.com/sites/default/files/d8/2019-07/docker-cheat-sheet.pdf)
- **Git Cheat Sheet:** Git commands for branching, merging, committing, workflows.
  - [Git Cheat Sheet Example](https://education.github.com/git-cheat-sheet-pdf/en/git-cheat-sheet-en.pdf)
- **Linux Command Line Cheat Sheet:** Basic Linux commands for navigation, file manipulation, system info.
  - [Linux Cheat Sheet Example](https://files.fosswire.com/2007/08/441399/fosswire-linux-cheat-sheet-v2.3.pdf)

## IV. System Design Cheat Sheet/Mental Model

- **System Design Principles:** Scalability, Reliability, Availability, Performance, Security, Cost, Maintainability.
  - [System Design Cheat Sheet/Principles Example](https://github.com/shashank88/system_design)
- **Common System Design Patterns:** Load balancing, caching, databases (SQL vs. NoSQL), message queues, microservices, APIs, CDNs.
  - [System Design Patterns Example](https://refactoring.guru/design-patterns/catalog)
- **CAP Theorem, ACID vs. BASE:** Fundamental concepts in distributed systems and databases.
  - [CAP Theorem Explanation](https://www.youtube.com/watch%3Fv%3DJhbLqE5Ob1A)
